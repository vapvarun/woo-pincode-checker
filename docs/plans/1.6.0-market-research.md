Performance / caching

Block checkout
- Not discussed by users of these plugins; core issue 68920 shows block postcode validation already diverges from server-side normalisation (wc_format_postcode) - need care.

## 4. Table stakes vs differentiators

Table stakes (every serious competitor; must-have 1.6.0)
1. Product-page checker, AJAX, works on simple AND variable products, shortcode + block placement
2. Admin pincode list with add/edit, CSV import/export (bulk, thousands of rows; no 190-row cap)
3. Per-pincode: serviceable yes/no, delivery days/ETA, COD yes/no, optional shipping fee
4. Cart + checkout validation that blocks order for unserviceable pincode, and disables/hides Add to Cart
5. Ranges and wildcards; alphanumeric (UK/CA/NL) formats; configurable length/regex
6. Remember pincode (cookie/session) across pages
7. Customisable messages and styling that fits themes/Elementor (design flexibility is the top review complaint)
8. WPML compatibility; HPOS compat; current Woo/WP/PHP support
9. Clean admin (no intrusive notices), secure (nonce, caps, rate-limit, no external calls)

Differentiators (few have; users ask)
1. WooCommerce Blocks Cart/Checkout support (none claim it)
2. Delivery date engine: processing days, cut-off time, weekends, holidays, ranges ("between Jun 10-12") shown at product/cart/checkout and in order email (PluginHive/Shopify ETA only; Phoeniixx users requested)
3. Cache-safe operation (page cache, CDN) plus saved pincode header widget / first-visit popup
4. Shop/archive page badge + hide-unavailable-products / category and per-product rules (users ask; Delivery Checker had it)
5. Unserviceable "notify me / waitlist" + analytics of searched and failed pincodes (Shopify AppJetty, retired Woo Delivery Checker) - turns failed searches into expansion demand data
6. Pincode-gated COD / payment gateway / shipping-method rules, plus order-level validation server-side
7. REST API (read/check for headless/mobile apps; admin CRUD) and hooks
8. Multi-warehouse / pickup point with per-origin ETAs
9. Multivendor (Dokan/WCFM) per-vendor service areas (wecreativez has Dokan only)
10. Geolocation auto-detect (Shopify ETA has it; privacy-sensitive, make opt-in)

Noise (low value / risky)
- Google Maps radius/polygon zones (heavy, API key cost; only WC Delivery Area Pro)
- AI pickup suggestions
- Usage-credit metering (Shopify pattern; hostile on Woo)
- Address autocomplete / lookup (different product category: Ideal Postcodes etc.)
- Shopify-style 50+ templates

## 5. Market notes
- Origin of demand: "pincode" wording = India (COD-heavy, 6-digit numeric PIN, courier serviceability). Vendors are largely India-based (Phoeniixx, SetuBridge Ahmedabad, iNext, wecreativez demo codes IN/UK/US). Plugin names in the WP.org top results use "Pincode" even though sellers serve UK/US/EU.
- Non-India users show up with format bugs: UK postcodes (alphanumeric, variable length, space, outward/inward codes -> need prefix matching like "SW1", "EC*"), US ZIP (5 / ZIP+4), Canada (A1A 1A1, FSA prefix matching), NL (1234 AB), AU/DE/FR numeric 4-5 digit. Must normalise (strip spaces, uppercase) and allow per-country format/regex; ranges for numeric and prefix/wildcard for alphanumeric. Support WooCommerce wc_format_postcode behavior.
- COD gating is a core India use case, less so UK/US; delivery date + cut-off matters everywhere (UK next-day, US local delivery).
- Pricing: Woo paid $17 (magerips) to $49 (wecreativez, 430 sales = ~$21k lifetime) to $60 (stale validator); Woo.com Delivery Checker was $79/yr; Shopify $5-20/mo. Sweet spot for a Wbcom Pro tier: roughly $49-79/yr with a capable free tier (free tiers elsewhere cap rules/postcodes, so a free tier with unlimited CSV rows is a market lever). Largest free plugin is only 600 installs, so the free category is small and winnable; the reference quality bar is Shopify (ETA 4.9 stars/507 reviews; FlipperCode 4.8/688).
- Trust angle: three competitors closed by wp.org (2 guideline, 1 security). Publicly stating security posture (no external calls, rate limiting, escaped output) is a real selling point.
