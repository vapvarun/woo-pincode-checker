# Install and activate

## Requirements

- WordPress 6.5 or higher
- PHP 8.1 or higher
- WooCommerce 8.0 or higher (the plugin declares WooCommerce as a required plugin)

## Install

1. Go to **Plugins > Add New Plugin > Upload Plugin**.
2. Choose the plugin zip file and click **Install Now**.
3. Click **Activate Plugin**.

You can also upload the `woo-pincode-checker` folder to `/wp-content/plugins/` and activate it on the **Plugins** screen.

## Find the settings

Go to **WB Plugins > Pincode Checker**. The tabs are:

| Tab | What it does |
|-----|--------------|
| Overview | Store status and the "Test a postcode" tool |
| Service Areas | Add, edit, filter and delete the postcodes you deliver to or block |
| Import / Export | Bulk-load areas from CSV, or download them |
| General | Where the checker shows, Add to cart behavior, postcode matching |
| Delivery Dates | Delivery estimate rules |
| Category Rules | Extra delivery days per product category |
| Checkout and COD | Checkout validation, cash on delivery, shipping cost by pincode |
| Display and Messages | Labels, messages and colors |
| Tools | System status, maintenance, data removal on delete |
| FAQ | Short answers to common questions |

Shop Managers can open and change all of these tabs, because access follows the `manage_woocommerce` capability.
