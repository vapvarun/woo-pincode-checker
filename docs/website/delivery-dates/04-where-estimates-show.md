# Where estimates show

Control these places with **Show the estimate on** on the **Delivery Dates** tab.

| Place | Setting | What shoppers see |
|-------|---------|-------------------|
| Product page | Product page | The "Arrives ..." line under the checker result |
| Cart and checkout | Cart and checkout (next to each shipping option) | Each shipping option label ends with "(arrives ...)" |
| Order details | Order details | "Estimated delivery:" on the thank-you page and the My Account order view |
| Order emails | Order emails | "Estimated delivery:" in order emails, HTML and plain text |

**Show delivery dates** turns everything off at once.

## Orders keep their promise

The estimate is saved on the order when the customer places it. It never changes afterward, even if you change your settings. The order edit screen shows it to staff as **Promised delivery**, with the earliest and latest dates. Staff always see it there, whatever the settings.

The shipping line on the order keeps the plain method name (for example "Flat rate") without the date, so shipping reports are not split by day.

## Daily refresh

Shipping rates are re-calculated each day, so "arrives Oct 8" does not stay in a cart into Oct 8.
